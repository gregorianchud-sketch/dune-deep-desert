# Dune: Awakening — Deep Desert Companion

Unofficial Flutter (Android) companion for the Dune: Awakening Deep Desert.

- **Map** – zoom/pan over the weekly Method.gg map (Standard / Single Player), glowing POI markers filterable by type, legend, tap for details and loot preview.
- **Loot** – PvE / PvP unique-schematic loot tables, searchable, grouped by POI, rarity tier badges and drop sources.
- **Endgame** – notes from the companion page.
- **About** – week label, data date, source credit.

Data: `tool/scrape.py` scrapes https://www.method.gg/dune-awakening/deep-desert-companion into
`assets/data/deep_desert.json` (bundled, works offline). CI re-scrapes on every build and falls back to the
committed JSON if the scrape fails. Marker positions are approximate (grid cell + 3x3 sub-cell).

Download the latest APK: [app-release.apk](../../releases/download/latest/app-release.apk)

Icon: original artwork generated by `tool/make_icon.py` (`assets/icon/icon.svg` / `icon.png`).
